Privacy policy

Last updated 15 October 2026

Kharcha is a personal app used only by its owner. This policy explains what it does with Google user data.

What Kharcha accesses

  • Kharcha asks for read-only Gmail access (gmail.readonly) and your email address.
  • It reads only transaction alert emails from the owner's banks and card issuers: HDFC Bank, SBI Card and HSBC.
  • It never sends, deletes or changes email.

How the data is used

  • From each alert, Kharcha extracts the amount, merchant, date and the account's last four digits.
  • These are stored as a transaction in the owner's own private database (Supabase, Mumbai region), protected by row-level security.
  • The data is used only to show the owner his own spending, budgets and notifications.

Sharing

  • When an alert can't be read by Kharcha's built-in rules, a masked copy of its text is sent to Anthropic's Claude API to extract the transaction. Names, email addresses, account numbers and similar identifiers are removed first.
  • Gmail data is not sold, not used for advertising, and not shared with anyone else.

Storage and deletion

  • The Gmail access token is stored encrypted (Supabase Vault).
  • Email bodies are not stored. Only the extracted transaction details are kept.
  • Access can be revoked at any time at myaccount.google.com/permissions.
  • Deleting the account removes all stored data.

Google API Services User Data Policy

Kharcha's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
